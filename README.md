# Shadowcr3-Relay
a push-to-talk walkie talkie  using 2 ESP32 board and 2 nRF24LA01+ and program them using arduino IDE , add a rechargeble 500mah or 1000mah battery and charge it using a charging module(TP4056 module) use microphone and speaker for voice and  I am aiming for real-time, low-quality voice communication without relying on wifi or the internet
